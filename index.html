As peças

Cada análise abre nesta mesma página. Os dados que a sustentam podem ser descarregados em CSV a partir de cada cartão.

Como se chega a estes dados

  1. A transcrição é numerada. Cada linha da peça recebe um número, que passa a ser a morada de todas as citações. Sem esse sistema de coordenadas nada do que se segue seria verificável.
  2. A peça é lida e inventariada. Um modelo de linguagem percorre o texto integral e regista personagens, relações, expressões vernaculares e recursos expressivos — sempre com citação exacta, localização e grau de certeza declarado.
  3. Cada citação é cotejada com o original. Antes de qualquer gráfico, o programa procura no manuscrito transcrito cada citação produzida. Fica marcada como confirmada, deslocada ou não encontrada — e esta última é tratada como erro, não como pormenor.
  4. Só então se desenham os gráficos. As visualizações são geradas por código a partir das tabelas já validadas, pelo que nenhuma figura pode mostrar o que as tabelas não contenham.

Limites destes dados

  • Não substituem a leitura. O que aqui está é uma sistematização verificável, não uma interpretação acabada: as leituras propostas carecem de confirmação por especialista.
  • O cotejo não valida a interpretação. Confirma que uma citação existe no texto — não que a leitura que dela se faz esteja certa.
  • As lacunas não foram resolvidas. Passagens ilegíveis e leituras alternativas do transcritor ficam assinaladas, e cada análise tem uma secção própria onde as declara.
  • A ortografia não foi modernizada. As citações conservam a grafia da fonte, porque a variação gráfica é ela própria matéria de estudo.
